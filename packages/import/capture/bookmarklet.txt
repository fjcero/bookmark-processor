X Bookmark Export v2 — bookmarklet URL

Setup (same as Siftly v1):
1. Show your bookmark bar: View → Show Bookmarks Bar
2. Right-click bookmark bar → Add bookmark / New bookmark
3. Name it: Export X Bookmarks v2
4. Paste the javascript: URL below as the URL
5. Go to https://x.com/i/bookmarks (logged in) and click the bookmark

A purple Export button and Auto-scroll button will appear. Scroll, then click Export
to download bookmarks.json (or likes.json on /username/likes).
